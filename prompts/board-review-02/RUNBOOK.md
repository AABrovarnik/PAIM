# Запуск совета №2
1. На Windows PowerShell в выбранной рабочей папке: git clone --branch docs/spec-v1 --single-branch https://github.com/AABrovarnik/PAIM.git PAIM-review02 ; cd PAIM-review02 ; git rev-parse HEAD. Если папка существует, используй новое имя. Зафиксируй SHA, не обновляй снимок между экспертами.
2. Создай отдельные рабочие копии из этого SHA (git worktree add --detach ../PAIM-codex <SHA>, аналогично ../PAIM-claude и ../PAIM-gemini). Не помещай чужие отчеты в рабочие копии. В каждой запускай установленный CLI интерактивно: codex / claude / gemini соответственно, если доступен; проверь --help и авторизацию. Не отключай sandbox/permissions. Выбери сильную доступную модель.
3. Вставь команду: «Прочитай prompts/board-review-02/CODEX_AUDIT.md и COMMON_PROTOCOL.md в том же каталоге. Выполни аудит, сохрани только указанный отчет. Не изменяй другие файлы, не делай commit/push/merge». Для Claude/Gemini подставь соответствующее имя. Если Gemini доступен только в AI Studio, загрузи документы снимка и оба промпта; попроси полный Markdown, сохрани локально.
4. После каждого запуска проверь git status --short: только отчет. Запиши фактическую модель и SHA. Не запускай другие эксперты с доступом к отчетам. Не публикуй реальные данные.
5. Передай три отчета председателю ChatGPT (загрузкой файлов или через отдельную ветку GitHub после разрешения). Председатель сверяет доказательства с ТЗ, объединяет дубликаты, фиксирует разногласия, формирует единый реестр, при необходимости раунд 2, предложенную редакцию v1.1 и повторную проверку блокеров. Не объявлять READY до закрытия блокеров и согласования владельца.
Команды запуска CLI не проверялись в текущей сессии, конкретные версии/режимы зависят от установки. Никакого исполнения моделей здесь не проводилось.
