# XVD Starter Kit v0.2 — Adaptive Edition (Codex)
Experimental draft. Nine operational Markdown documents plus README and CHANGELOG; no executable code. Preserves all 14 principles and three risk modes from XVD v0.1. Adds Lite profile inside ENGINEERING, evidence-based verification, compact cost tracking, Windows preflight, explicit CHALLENGE and simplicity review.
## Install on a separately authorized target
Inspect existing AGENTS.md and docs/xvd/; merge compatible instructions, never overwrite conflicts. Copy AGENTS.md to target root; copy eight other operational files to docs/xvd/. README/CHANGELOG optional. Confirm version; do not install in active A/B evidence folders or PAIM Zero pilot. Start a fresh Codex session in target; use REVIEW_PROMPTS A. Existing subscriptions only; no Claude or new infrastructure.
## Quick start
Provide goal, scope, observable criteria, permissions and budget. For small reversible tasks use ENGINEERING/Lite: one compact record, actual preflight, challenge, minimal diff, behavior evidence and cost/lesson. No mandatory document generation. Use Full/Critical when risk requires; mandatory safety stays.
