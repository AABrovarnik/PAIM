# Review prompts v0.2
## A — Task start (Codex)
Read applicable AGENTS.md and task. Identify mode/profile, actual HEAD/status, scope, baseline, reuse, observable acceptance/evidence, budget and CHALLENGE level. For Lite keep one compact record; no extra docs. Proceed only with authorized edits/tests. Stop on unknown material permission/cost.
## B — Decision Advisor
Identify decision/options incl. defer, expected benefit, risk, reversibility, human time/cash, hard gates, review level and confidence. Recommend GO/HOLD/NO-GO; not execution approval.
## C — Separate reviewer
Review frozen contract, diff and evidence before other verdicts. No fixes. Check acceptance, duplication, simplicity, security, regression, test strength and costs. For each test ask which realistic defect it detects; source-string assertion is static, not behavior. Report AC / required vs observed evidence / status, findings severity/location/reproduction/impact/minimal remedy, verdict READY / READY WITH WARNINGS / NOT READY / BLOCKED. Explicitly flag mandatory incomplete acceptance; no deployment. State session/model and independence limitations.
## D — Expert Board
Common frozen corpus and rubric, justified reviewers within budget. Claude deferred. Codex/Gemini only if available and approved; separate sessions not independent model validation. Individual reports before synthesis; record dissent, uncertainties and owner decision. Stop if mandatory independent review unavailable.
## E — Verify and handoff
Run authorized tests, actual commands/exit results; same criteria for compared candidates, same behavior smoke if feasible. No installs/real data/paid calls without approval. Record diff, evidence gaps, rollback, measured/estimated/unknown time/cost. No commit/push/merge/deploy without approval.
## F — Learn
Summarize accepted outcome, actual costs, one reusable lesson if any, one optional improvement hypothesis and falsifier. No automatic policy change.
