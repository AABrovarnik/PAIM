TCO over agreed horizon = setup + recurring + usage + maintenance + exit cash; hours tracked separately. Existing subscriptions and VPS are not zero-cost even with $0 new spend. Do not double count. Net saved hours = baseline active hours minus actual active hours including overhead. Report sample size and uncertainty, not ROI without evidence.
