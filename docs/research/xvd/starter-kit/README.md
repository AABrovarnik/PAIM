# XVD Starter Kit v0.1 — Codex Edition
Experimental reusable documentation kit. No executable code or installation. Origin: XVD concept v0.1 (research/xvd), 14 principles retained. This directory is a distribution template, not repository-wide agent policy until explicitly installed in a target project.
## Install (manual, on separately chosen target)
1. Inspect existing AGENTS.md and docs/xvd/; don't overwrite conflicts. Copy AGENTS.md to target root; copy seven other operational MD files to docs/xvd/. README optional. Review and adapt local instructions.
2. Open target folder in Codex Desktop, CLI or VS Code. Start with prompt A in REVIEW_PROMPTS.md. No need for OpenClaw or Claude.
3. Supply real intent, acceptance criteria, authorized scope and resource limits. Use least sufficient mode.
## Validation proposal
One small synthetic or real low-risk task in a separate authorized project, compare direct Codex workflow with kit-assisted workflow using same criteria and track active minutes, elapsed, accepted result, rework and cost. Record limitations. No claim of improved quality until measured. Keep PAIM Zero pilot unchanged.
