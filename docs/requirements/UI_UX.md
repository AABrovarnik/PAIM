# UI/UX v1.1
Адаптивный русский интерфейс desktop-first, доступен на телефоне. WCAG 2.2 AA — проектная цель, не сертификация. Удобство To Do, Todoist, TickTick; проектный режим SingularityApp; ритуалы Sunsama; прогрессивное раскрытие Amazing Marvin. Не копировать визуальные активы.
## Навигация
Простой режим по умолчанию (preferences.ui_mode=simple): Мой день (= Сегодня), Входящие, Предстоящие, Без срока, Календарь, Ожидаю, Обзоры, Настройки. Расширенный добавляет Проекты, Цели/идеи, Горизонты, Матрицу; расширенные I/U/R/B и зависимости раскрываются по запросу. Переключение в один клик, сохраняется на сервере, одна БД. На 360px нижняя навигация День/Входящие/Календарь/Еще, постоянный +, остальные разделы через меню. P1 Гант, месяц, фокус.
## Экраны и операции
- Мой день/Сегодня: единое представление по A02; до 3 ранжированных результатов, другие выбранные задачи, просрочки, дедлайны, блоки, встречи, текущая емкость/перегрузка, +N без оценки, минуты вне окна, stale indicator. Не скрывать жесткие сроки и блокировки. Быстрый ввод создает ready и включает в выбранный день без присвоения срока или ранга. Чипы сегодня/завтра, время и проект без LLM; дата/тип даты видны перед сохранением. На desktop список и правая колонка [Календарь | Ассистент], по умолчанию Календарь; при отключенном AI календарь занимает колонку. На mobile вкладки сохраняют день, фильтр и текст в памяти текущей страницы.
- Утренний ритуал: кнопка «Спланировать день»; четыре шага Входящие→до 3 результатов→Нагрузка→Подтвердить. Любой шаг пропускается, результат сохраняется через ручной API, перезагрузка не теряет план. Предложение по правилам A01, пользователь меняет выбор. Подтверждение только локального плана, не внешнего календаря. После изменений видна версия/история; завершение задачи обновляет прогресс, не требует повторного подтверждения.
- Входящие: две секции «Из источников» (inbox_items new, источник, цитата, неопределенность, accept/dismiss/merge) и «Сырые задачи» (tasks inbox, редактировать/перевести ready). Принятие ручного элемента без LLM; пакетный preview с per-item итогом. Не дублировать задачу после принятия.
- Предстоящие, Без срока: фильтры A02; окно предстоящих 30 дней, сгруппировано по ближайшей дате; фильтр без срока не включает запланированные. Горизонты: сегодня/7/30/90/год, цели, вехи, сроки, часы и неоцененные, отдельные просрочки и undated цели. Пересекающиеся горизонты не суммируются.
- Карточка: название, статус, дедлайн, блок, исполнитель, проект. Быстрый приоритет high/medium/low/unset; стандартная матрица Q1–Q4 или «Требует оценки»; важные без срока видны отдельно; полный балл только при достаточных данных. Расширение: отдельные редактируемые «Если выполнить»/«Если не выполнить», I/U/R/B, подзадачи, зависимости, напоминания, источник, история. AI не перезаписывает ручные оценки.
- Календарь: день/неделя; отдельные подписи/иконки/рамки для busy Google, free/transparent, local event, task block, locked block, hard deadline. D&D и эквивалентная кнопка/клавиатурная форма. Если у задачи несколько блоков, явный выбор экземпляра; перенос не меняет дедлайн. Без оценки предложить 30 минут с видимым редактированием до сохранения (estimate остается null). Mobile bottom-sheet «В слот»: выбрать день, свободный интервал, длительность, подтвердить; детерминированные интервалы, не автоплан. 360px до 4 тапов для задачи с известной длительностью и свободным интервалом сегодня, при редактировании больше допустимо. Пересечения предупреждаются, ручной override только явный; stale синхронизация заметна.
- Проект: дерево, прогресс по листьям, вехи, зависимости; мобильное раскрытие по уровню без обязательного полного дерева. Ошибки циклов объяснять. Гант P1.
- Ожидаю: две секции поручения и мои обязательства. В карточках задачи/мероприятия создать/редактировать/исполнить/отменить обязательство: контрагент, результат, срок, контрольная дата. Не закрывать автоматически. Быстрый пресет «Жду ответа от X до даты» в одном диалоге, контакт/задача/поручение, drafted по умолчанию, sent только после явного указания факта передачи. Никакой отправки. submitted→проверка→verified либо возврат in_progress; после verified предложить явно завершить задачу. Скопировать текст напоминания, напомнить себе.
- Цели: критерий достижения, горизонт, связанные работы, прогресс по связанным задачам с пояснением что это не фактическое достижение метрики, идеи, архив.
- Обзоры: утро/вечер/неделя; факты отдельно от советов, заметки владельца, ручной режим без LLM; до 3 рекомендаций, раскрытие остальных. 
- Настройки: timezone IANA (предупредить о сохранении старых зон), ui_mode, рабочие окна, резерв, веса, тихие часы, источники/фильтры, память, интеграции, расходы, экспорт, retention, корзина.
## Состояния и ошибки
Loading/empty/error/retry, offline banner (не обещать офлайн запись; удерживать несохраненный ввод в памяти формы при сетевой ошибке и переключении вкладок, без автоматической записи в localStorage), AI unavailable/budget exceeded, stale sync, conflict, uncertain. 409 локального объекта: сравнить «мое/серверное» по измененным полям, оставить серверное или явно повторить с новой версией и повторной валидацией. Не перезаписывать молча. Внешнее действие: diff, календарь, источник, срок подтверждения, статус после 202 (не считать applied); expired/conflict -> кнопка нового preview; uncertain -> сверка/ручное разрешение, не кнопка повтора. ETag conflict требует повторного согласования. Отказ/истечение не теряют ввод. Для recurrence scope dialog single/future/all с preview, исключениями, пропусками календарных дат/DST и блокировкой несовместимых завершенных экземпляров. Destructive отдельное подтверждение.
## Приемка UX T17
5 повторов быстрого ввода отдельно desktop и 360px (3 только название, 2 дата/проект через чипы; отсчет от открытого «Мой день» до появления записи, LLM отключена), медиана <10 сек. Утренний ритуал <=4 шагов и <=10 мин в пилоте, все шаги можно пропустить. 360px touch targets >=44x44 CSS px, основные операции клавиатурой с видимым фокусом (ориентир 2px/3:1), не перехватывать ввод горячими клавишами; тип объекта не только цвет. 1280x720 календарь показывает 8 часов при компактной сетке или едином управляемом скролле без конфликтующего вложенного скролла. Ввод не сбрасывается при 409/сети/expiry. Замер на реальном прототипе, не оценка по тексту. Никаких личных данных в репозитории.
