# UI/UX
Адаптивный русский интерфейс desktop-first, доступен на телефоне. Простота To Do, расширенный режим проекта. WCAG 2.2 AA как проектная цель, проверить клавиатуру/контраст/labels, не заявлять сертификацию.
## Навигация
Мой день (default), Входящие, Календарь, Ожидаю, Проекты, Цели/идеи, Горизонты, Обзоры, Настройки; приоритеты как фильтр/матрица. P1 Гант и месяц.
## Экраны
- Мой день: 3 результата, встречи, блоки, просроченные/незапланированные, доступная емкость, быстрый ввод, завершить/перенести. Не скрывать жесткие сроки.
- Входящие: источник, фрагмент, предложенные поля, неопределенность, принять с редактированием/отклонить/объединить. Пакетный выбор показывает все изменения.
- Карточка: заголовок, статус, дедлайн, блок, исполнитель, проект; расширение — подзадачи, последствия, оценка, зависимости, напоминания, источник, история. 
- Календарь: день/неделя, легенда для события/блока/дедлайна, часовой пояс; перенос мышью и эквивалентная кнопка/форма; конфликт не меняет исходное до решения.
- Проект: дерево, прогресс по листьям, вехи и зависимости; запрещенные циклы объяснять. Гант P1.
- Ожидаю: исполнитель, статус, срок, дата проверки, ожидаемый/фактический результат; напомнить себе.
- Цели: критерий достижения, горизонт, связанные работы, идеи, архив.
- Обзоры: факты отдельно от AI-рекомендаций, дата последней синхронизации, ручной обзор доступен без AI.
- Настройки: timezone IANA, рабочие окна, резерв, веса, тихие часы, источники/фильтры, память, интеграции, расходы, экспорт, корзина.
## Состояния
Пустое, loading, error/retry, offline banner (не обещать offline запись), AI unavailable, stale sync, conflict, budget exceeded. Внешнее действие показывает diff, источник, получателей/календарь, срок действия подтверждения. destructive — отдельное подтверждение. После 409 предложить обновить или сравнить.
## Приемка UX
5 повторов быстрого ввода владельцем: медиана <10 сек; основной путь доступен клавиатурой; 360px без горизонтального скролла кроме календаря/дерева с обозначенным контейнером. Не использовать цвет как единственный индикатор. Никаких реальных данных в скриншотах GitHub.

## Согласованные референсы (24.11.2026)
Todoist — основной UX и быстрый ввод; TickTick — календарь, карточка и матрица; SingularityApp — проектная иерархия и Telegram; Sunsama — дневная загрузка и недельный обзор. Microsoft To Do — простота, MS Project — проектные функции; Amazing Marvin — постепенное раскрытие, Motion — будущие предложения перепланирования. На desktop экран «Мой день»: навигация слева, задачи в центре, календарь и AI справа; на мобильном панели переключаются. P0 умные списки Сегодня/Предстоящие/Без срока/Ожидаю, единый список+календарь, короткий ритуал планирования (проверка входящих, 3 результата, оценка нагрузки, подтверждение плана). P1 фокус на одной задаче. Без копирования визуальных активов.
